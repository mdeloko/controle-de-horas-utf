# Meninas Digitais — Controle de Horas

Frontend do sistema de registro e validação de horas complementares do projeto Meninas Digitais.

## Stack

- React + Vite + TypeScript
- shadcn/ui + Tailwind CSS
- React Query + react-hook-form + Zod
- Recharts

## Executar localmente

```bash
npm install
npm run dev
```

O frontend espera o backend rodando em `http://localhost:3000`.
